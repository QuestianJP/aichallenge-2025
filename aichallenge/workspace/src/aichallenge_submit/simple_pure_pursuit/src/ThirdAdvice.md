Stanley法のゲイン（`stanley_gain`）は、車両の挙動に大きく影響するため、**自動チューニング**が非常に有効です。以下に、現実的かつ実装可能な方法を紹介します。

---

## 🔧 Stanleyゲインの自動チューニング方法

### 方法①：**グリッドサーチ（オフライン）**
#### 概要：
- 複数のゲイン値（例：0.1〜3.0）を試して、**振れ幅・軌道誤差・ラップタイム**などの評価指標を記録。
- 最も良い結果を出したゲインを選択。

#### 実装ステップ：
1. ログに以下を記録：
   - 横方向誤差（`e`）
   - 方位角誤差（`theta_e`）
   - 操舵角（`delta`）
   - 軌道からの逸脱量
2. ゲインを変えて複数回走行
3. 評価関数（例：誤差の積分値 + 操舵角の変化量）で最適値を選定

#### メリット：
- 安定性が高く、実装が簡単
- シミュレータでも実施可能

---

### 方法②：**オンライン適応制御（リアルタイム）**
#### 概要：
- 走行中に誤差が大きい場合はゲインを増加、誤差が小さい場合は減少させる。
- フィードバックループでゲインを調整。

#### 擬似コード例：
```cpp
if (std::fabs(e) > threshold_high) {
  stanley_gain_ += gain_step;
} else if (std::fabs(e) < threshold_low) {
  stanley_gain_ -= gain_step;
}
stanley_gain_ = std::clamp(stanley_gain_, min_gain, max_gain);
```

#### メリット：
- 状況に応じて柔軟に対応
- 実車での微調整に有効

#### 注意点：
- ゲインの変化が急すぎると振動を引き起こすため、**スムージング**が必要

---

### 方法③：**機械学習ベースの最適化（高度）**
- 過去の走行データを使って、誤差とゲインの関係を学習
- 強化学習やベイズ最適化などを使う

これは時間とリソースが必要なので、競技の残り時間を考えると、**方法①（グリッドサーチ）**が最も現実的です。

---

## ✅ おすすめの実施方法

1. **Stanley法で走行ログを記録**
2. **ゲインを 0.5, 1.0, 1.5, 2.0 などで試行**
3. **横方向誤差と操舵角の変化量を評価**
4. **最も安定した走行を示すゲインを選択**
